# Legacy Vault

Legacy Vault landing page, built with the Next.js App Router.

## Integration

Place `page.tsx` at `src/app/legacy-vault/page.tsx` in the host Next.js application.

This page uses React, Next.js, Framer Motion, Lucide React, Tailwind CSS, and the host application's shared `Button` and `Card` components at `@/components/ui/button` and `@/components/ui/card`. It also uses the host application's theme tokens and `font-headline` font class.

This repository contains the landing page source only. The parent application's configuration, shared components, and environment files are not included, so this is not yet a standalone runnable application.
